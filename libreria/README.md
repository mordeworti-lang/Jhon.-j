## Es un gestor de ventas e inventario.
# Descripcion
Es un sistema pensado,  la gestion de una libreria, la cual requeria:
una gestion de un inventario, de ventas y registros de estas, como tambien manejar un historial de dichas ventas, registros de clientes e historiales de compra igual mente.
Reportes de los 3 libros mas vendidos y ventas por autor.

Todo el codigo tiene validaciones avanzada, y estas muy, muy, pero muy, argumentado par aque cualquiera pueda enteder.

# como esta dividido el trabajo

## El crud de inventario 
este esta dividido en 6 opciones del 0 al 5
siendo, el 0 la del volver al menu principal, las demas opciones son:
1. Agregar libro. 
2. Actualizar libro. 
3. Eliminar libro.
4. Buscar libro. 
5. Mostrar todos los libros. 

## ventas 
este esta dividido en 2, salir y agregar al carrito
1. Este registra, los clientes y verifica si ya esta registrado, si, si agrega al hsitorial de este, la compra nueva,si esta es cerrada con exito. 
si el cliente no esta registrado este lo registra, le genera ID, si compra esta se registra, sino solo se gurga el cliente. 
2. vuelve a menu principal

## reportes 
esta tiene 5 opciones del 1 al 5, siendo la 5 volver al menu
1. Ver historial de un cliente
esta mustra los datos, del cliente, todos, el nombre, la fecha y hora de registro, lo que a comprado, y la cantidad total de lo que a gastado, pero de uno solo.

2. Ver todos los clientes y sus compras 
este muestra a todos los clientes, los datos de estos.

3. Top 3 libros más vendidos
muestra los 3 libros, mas vendidos, y todos los daos de estos.

4. Ventas agrupadas por autor
esta muestra las ventas, que a tenido cada autor, contando todos los libros de cada autor.
